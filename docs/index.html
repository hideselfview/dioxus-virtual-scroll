dioxus-virtual-scroll

A virtual scrolling grid component for Dioxus. Renders only visible items plus a buffer, using spacer elements to maintain scroll height.

Features

  • Grid layout with auto-calculated columns based on container width
  • Two scroll modes: container scroll (grid has its own scrollbar) or window scroll (uses browser scrolling)
  • Automatic measurement of item heights for accurate layout
  • Efficient updates with ResizeObserver and rAF-throttled scroll handling

Live Demo

Interactive demo with toggle between container and window scroll modes.

Quick Start

cargo add dioxus-virtual-scroll
use dioxus_virtual_scroll::{VirtualGrid, VirtualGridConfig, RenderFn, KeyFn};

let config = VirtualGridConfig {
    item_width: 200.0,
    item_height: 280.0,
    buffer_rows: 2,
    gap: 16.0,
};

rsx! {
    VirtualGrid {
        items: albums,
        config,
        render_item: RenderFn(Rc::new(|album, idx| rsx! { ... })),
        key_fn: KeyFn(Rc::new(|album| album.id.clone())),
    }
}
